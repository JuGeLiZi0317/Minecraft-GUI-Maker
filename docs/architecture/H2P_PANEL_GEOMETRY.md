# H2-P Panel 独立几何合同

Panel 的 `bounds` 为设计区坐标系下的整数 `{x,y,w,h}`，左上为 (0,0)，最小 8×8 且完全位于设计区内。设计区大小独立；用户可在取消选择组件后于 Inspector 提交四个字段。欲为未来顶部标签预留 28 GUI px，可设置 Panel Y=28，并相应缩小高度；不自动修改设计区，也不强制该布局。本批不实现标签组件。

Schema 0.9.0 才允许显式 `background.bounds`。旧版缺少该字段时，运行时解释为 `(0,0,设计区宽,设计区高)`；读取、保存和导出不隐式迁移。首次提交独立几何与版本升级是同一撤销事务。设计区缩小时若显式 Panel 超界则拒绝，保留原文档。Panel 设为无底板会移除它的几何；更改底板样式时保留几何。

Canvas 和设计区 PNG 在相同全局坐标绘制 Panel，PNG 仍为整个设计区；Panel 以外在 1× 设计图中透明（放大参考图保留既有深色衬底）。Panel 背景图仍为 512/768/1024 方形纹理，1 图像像素为 1 GUI px；设计区位于纹理左上 (0,0)，Panel 位于同样全局坐标，其余区域透明。导出时继续采样纹理的整个 `contentWidth × contentHeight` 设计区，绘制到设计区原点；不要将 Panel 局部矩形再次偏移或把整张方图拉伸。规格、manifest 与 PNG 元数据均记录 panelBounds；旧版隐式几何输出为全幅数值。Panel 图仍只含底板，不含节点。现有尺寸预算、字体和资源快照合同不变。

本批不修改素材、不提供游戏运行时实现；物理 DPR、不同浏览器及游戏内视觉仍未验证。
