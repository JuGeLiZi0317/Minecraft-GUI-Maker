# H2-B 标签编辑视图修复合同

2026-10-29。Schema 仍为 0.11.0；组内唯一初始 `selected` 的严格校验和关联删除保护未放宽。已有规则以 `H2B_TAB_GROUP_CONTRACT.md` 为准。

## 复现与定位

无用户资源时，H2-A 的中性回退函数对选中/未选中均画完全相同的图。通过两个同组标签（权威 selected 分别为 true/false）的浏览器像素测试，在修改前复现两个回退图完全相同，原始报告 `../../h2b-repro-before.json`。这证明该场景的状态无法从图上区分；不能据此认定用户遇到的所有真实资源场景都有相同原因。回退图现按有效状态使用不同灰度和边框，仍是中性占位，不冒充原版贴图。

静态核查确认：Schema 拒绝组内零个或多个初始选中；Inspector 的组变更由 `configureTab` 原子更新；测试点击只写会话覆盖；Canvas 的 Sprite 和 Panel 前后层均依有效选中节点确定。有资源的两标签同列实测通过像素对调，含 Panel 4 px 重叠，见 `../../h2b-repro-after.json`；这验证该复现条件下没有两个有效 selected，但不推断用户未提供的其他资源或具体项目状态。

## 三种状态

- **设计初态**：JSON 的 `selected`；所有 PNG、JSON、规格、Prompt、manifest 和 ZIP 按此状态生成。编辑视图和行为测试的选择均不进入领域文档、revision、历史和 IndexedDB。
- **编辑视图**：右侧“标签编辑视图”按组列出标签，显示正在编辑项和设计初始项。点击“编辑”切换会话视图，非活动内容淡显且仍可选；可从图层选择非初始标签的内容进行编辑。无效或已删除的会话引用回退到设计初始项；导入、恢复、刷新和进入只读 GUI Scale 预览时清除会话选择。
- **行为测试**：进入测试从设计初态开始，并清除编辑视图选择；点击组内标签只修改测试会话状态。重置、退出或关闭测试后，编辑视图回到设计初态。F2 显式可见性与组范围规则不变，标签点击不递归触发 F2 或创建 Screen。

选中内容节点时 Inspector 显示其关联标签，多个标签引用时标注共享；在各标签的内容列表勾选或取消并保存即可关联/解除。关联关系、节点编辑本身仍是可撤销的设计事务；仅编辑视图切换不产生事务。

真实 Minecraft 游戏内行为、资源包差异和物理 DPR 不在本次验证范围。
