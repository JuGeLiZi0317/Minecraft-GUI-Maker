# 多 Screen 工作区画布

Screen 仍是同一权威项目 `screens` 数组中的独立设计，不是独立项目文件；组件坐标、Panel 与行为均相对所属 Screen。现有 0.12.0 JSON 包含所有 Screen，派生 PNG、规格和 ZIP 仍按原有保护禁止导出。

同一 Konva 工作区绘制当前 Screen 与其他 Screen。其他画布复用现有组件、Panel、字体和资源渲染；点击非当前画布可切换，拖动画布标题栏只改变工作区位置。结构树继续负责新增、重命名、删除；已绑定导航目标的 Screen 由现有删除保护阻止删除。切换前会提交已登记的草稿，非法草稿阻止切换。当前画布视图的缩放和平移可用于观察多画布。

布局坐标属于编辑器会话，不写入设计 JSON、IndexedDB、设计 revision、历史或导出。新建 Screen 时默认横向排列并缩小视图；刷新、导入或恢复项目会重置画布摆放。画布布局自身不提供撤销或跨刷新保存；设计内容的撤销重做仍使用既有项目历史。删除 Screen 后布局记录不会变成设计内容，撤销删除可继续使用本次会话中的布局。

其他 Screen 展示其设计初态，标签编辑视图和交互／行为测试状态仍只属于当前 Screen。多 Screen 派生导出、声明目标绑定界面和游戏运行时导航均未在本批实现。
