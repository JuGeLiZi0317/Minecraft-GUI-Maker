# H1 组件合同（实施中）

目标版本 Minecraft 1.21.1 / NeoForge 21.1.244，源码证据见 `../minecraft/H1_COMPONENT_SOURCE_AUDIT.md`。本文冻结设计，不表示组件已经实现或测试通过。

## 版本与兼容

`0.4.0` 增加 Checkbox 与 CycleButton；0.1.0–0.3.0 保留原有校验，禁止包含新组件。读取旧项目不升级、不改写节点；首次添加新组件时在同一个历史事务中升级至 0.4.0。撤销恢复原快照；Panel 操作不得降低 0.4.0。导入和本地恢复继续先完整验证后替换；不对 IndexedDB 已存记录做后台迁移。旧版应用无法读取 0.4.0，应明确说明，不得静默降级。严格拒绝未知组件、重复选项 ID、空选项及悬空初始 ID。

## Checkbox

`bounds` 为整数 GUI px 设计参考边界，用于选择、移动和设计空间提示，不承诺是游戏控件实际边界；`maxWidth` 是独立的原版 builder 参数，不能由任意高度替代。固定方框 17×17，文字左侧距方框 4 px；参考排版使用 `maxWidth` 和浏览器字体近似换行，按源码行高 9 及方框垂直居中计算。游戏字体不同导致实际宽高及换行仍需游戏实测。参考边界可调整，但调整它不会修改 maxWidth 或承诺影响游戏构造高度。

采用非阻断溢出提示：基于当前浏览器字体测量可见的文本包围范围，若超出参考边界或设计区，在 Inspector 中提示；不要把该近似结果作为导入拒绝标准。实际游戏可能产生不同溢出；导出规格需明确这一点，不能把参考边界或浏览器测量当成已验证的运行尺寸。Sprite 由 selected 和实际预览 focus 选择；悬停不产生聚焦。设计初态、预览临时状态分离；PNG 使用设计初态和非焦点状态。

## CycleButton

选项包括稳定唯一 ID 和独立 `TextSpec`；至少一项，初始 ID 必须存在。显示格式区分 `value-only` 与 `name-and-value`。普通设计模式不执行业务。若实现交互预览，前进、Shift 后退及滚轮切换只改变会话状态，不能改动文档、历史或持久化；它不是 Java 回调。背景复用 AbstractButton 的正常、高亮和禁用 Sprite；PNG 以初始选项和非悬停状态绘制。

## 待实施与验证

画布及 PNG 必须共用资源选择、纹理绘制、文本近似和初始状态规则；资源失败须可见诊断。分别覆盖领域、渲染、浏览器编辑、JSON、历史和持久化；保留原有完整回归。游戏内视觉及不同字体下的尺寸与换行均为 PENDING。
