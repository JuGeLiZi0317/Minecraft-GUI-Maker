# F2 单 Screen 有序行为合同

Schema 0.8.0 允许规则使用严格 `{id,event,actions:[...]}`，每条规则 1–50 个动作，动作仍仅为已有的 `set-text`、`set-visible`、声明式 `open_screen`。`set-text` 只允许指向 StringWidget；`set-visible` 可指向当前 Screen 中任一已有节点；`open_screen` 必须指向已声明目标。事件来源仍限 Button、Checkbox 和 Rectangle。所有引用按稳定 ID 验证，禁止未知字段、空动作、越界及悬空引用；变量、条件、循环和脚本仍不支持。

旧 0.6.0/0.7.0 单动作 `{id,event,action}` 按原样读取、保存和导出，不自动转换。首次将规则编辑为有序数组时，规则与 0.8.0 升级属于一个历史事务；撤销恢复旧文档快照。0.8.0 可混合旧单动作和新动作数组，后续 Panel、文字阴影、目标 Screen 和节点操作不得降级。规则顺序为文档数组顺序；相同事件的每条匹配规则按该顺序执行，其内部动作按 actions 数组顺序执行。旧 action 等效单项数组。同一目标后执行的设置覆盖先前设置；不递归触发事件。`open_screen` 仍仅是声明式意图，浏览器不会切换 Screen。

行为编辑器以组件 ID、类型与组件现有文字说明目标，不新增名称字段。动作可添加、删除、上下移动；文字宽度使用当前预览字体和既有 9 GUI px 浏览器测量，提示不阻断保存、不改变 bounds；游戏字体宽度仍需实测。行为面板可收起以点击实际画布；预览仅修改会话覆盖层，重置、关闭面板或文档变更时清除。

删除被任一规则作为来源或动作目标引用的组件时拒绝操作并提示先修改/删除规则；不再采用 F0/F1 历史的自动级联删除。目标 Screen 被引用时继续拒绝删除。规则删除或重新指定目标是显式解除关联；撤销、重做和 IndexedDB 遵循现有文档事务。

导出合同 0.6.0 将未经改写的规则与顺序写入同一快照的权威 JSON、结构化规格、Prompt、manifest 和 ZIP。实现者负责实际 Java 回调、组件引用和游戏状态；浏览器预览不是游戏或服务器验证。F0 单次用户实机反馈仅覆盖其具体设计，不证明 F2 行为。
