# H2-B 标签组合同

Schema 0.11.0 为 CreativeTab 提供可选 `groupId` 和 `contentIds`，组 ID 和内容均使用稳定 ID。无组标签保留 H2-A 的独立外观。组内恰好一个 `selected` 初态，用户设置新初态、组加入/迁移、选中标签删除时对同组的必要调整与操作同一历史事务；未涉及标签组的旧文档不静默升级。内容引用只允许当前 Screen 非标签节点，不允许悬空或重复；被引用的内容节点删除前须解除关联。一个内容节点可被同一组的多个标签共享，但不能同时属于不同组。

标签组接管关联节点的默认显示：选中标签引用该节点时显示，未引用时隐藏；原节点 `state.visible` 保留在权威文档中，解除关联后恢复其原始语义。共享节点在多个标签引用时，只要当前选中项引用它就显示，不依赖动作顺序。设计画布将非活动内容淡显以便编辑；行为测试中隐藏它们。设计 PNG 使用初始选中项、无临时覆盖；画布交互仅改变会话状态，不改变 revision、历史或 IndexedDB。

F2 按既有规则与动作顺序执行，显式 `set-visible` 可以进一步隐藏活动标签的内容；无论 F2 写入什么值，非活动标签内容均由组范围隐藏。F2 对关联节点的临时可见性覆盖会持续到重置，切换标签不清除它；F2 文本等其他覆盖仍按原规则处理。标签点击只改变组选择，不递归触发 F2 规则；F2 不提供标签选中动作，避免两个选中状态源。隐藏或禁用的事件来源不可触发。点击、状态与内容切换的游戏端逻辑均须由开发者实现，非 Java 生成或服务端行为。

资源与视觉沿用 H2-A，绘制层随临时选中状态切换；PNG 和其资源快照采用设计初态。权威 JSON、结构化规格、Prompt、manifest 与 ZIP 保留同一快照的组关系、初态与 F2 意图。缩放、底部标签、图标、多 Screen、Blockly 和复杂容器均不在本批。
