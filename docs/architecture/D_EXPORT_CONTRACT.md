# D导出合同 0.1.0（冻结）

2026-10-27。以本轮用户指定要求冻结。仅授权D：设计区PNG、结构化实现规格、Markdown实现Prompt及原始权威JSON的一致导出。不开展E～H，不导入图片/游戏资产，不生成Java或行为积木，不借机重构已验收A+B+C。

## 单一快照与输入边界

一次“导出规格”先同步校验所有尚未提交的领域输入，包括就地文字、属性表单、设计区宽高。全部合法后按既有编辑事务提交；非法输入阻止整批导出，显示字段错误，不以旧值冒充当前输入。活动拖动和组合输入尚未完成时也拒绝，不猜测其中间值。编辑器Zoom/Pan及游戏GUI Scale预览是会话参数，不需要写入或提交到领域文档。

输入提交完成后，只读取一次当前文档，经过既有严格校验，深拷贝并递归冻结。此后所有异步步骤只接收该快照，绝不再次读取活动store、Konva场景、DOM表单或IndexedDB。用户可以在生成期间继续编辑；生成结果仍明确对应旧快照，不会混入新设计。

每批关联标识：exportId（UUID）、createdAt（UTC ISO时间）、projectId、revision、schemaVersion、catalogVersion、target，以及权威project JSON**精确UTF-8文件字节**的SHA-256。revision可能因undo下降或不同导入而重复，因此不能单独作为唯一批次标识。所有派生结果都带相同关联标识。

合法未提交输入本身仍是普通编辑：可能增加revision/历史并触发C自动保存；导出操作本身不增加历史，不改变选择、视图、预览、存储身份或文档。无待提交输入时，成功或失败导出均不改变历史。逐项预校验通过后才提交，避免已知非法输入造成部分表单先提交。

## 文件及权威关系

| 文件 | 合同 |
|---|---|
| `<batch>.project.json` | 原始Schema 0.1.0项目JSON；**唯一权威设计数据**，保留全部ID、属性、来源及extensions，允许重新导入；不添加导出字段。文件为两空格格式JSON加结尾LF |
| `<batch>.design.png` | 设计区参考图，像素宽高恰等于designSize宽高，1 PNG px = 1 GUI逻辑单位，左上角(0,0)，x向右/y向下；透明底、按节点顺序绘制可见初态，不包含隐藏节点、选择框、控制点、网格、标题栏或GUI Scale窗口外框 |
| `<batch>.implementation.json` | 只读派生规格，format/version/authoritative=false及权威JSON文件名/摘要；严格分facts、designIntent、unverified，几何和属性带原文档sourcePath；不接受此文件回导项目 |
| `<batch>.prompt.md` | 基于同一派生规格生成的确定性实现Prompt；明确目标版本、原生类别、绝对逻辑坐标与居中设计区语义；事实/设计意图/OPEN分节。它不是另一套数据模型或游戏验证报告 |
| `<batch>.manifest.json` | 批次标识、坐标说明、文件名/MIME/字节数/SHA-256、图像尺寸和近似性质。列出前四文件的摘要；不对自身计算递归摘要 |

批次文件名前缀包含revision与exportId短码，不使用不受控的项目标题构造路径。完整exportId/文档摘要用于关联，不依赖短码唯一性。

不打包ZIP，避免跨入E。全部文件生成并验证成功后，统一呈现五个独立下载入口；用户逐项点击下载，避免浏览器阻止自动多文件下载。任一步失败均不发布部分结果，并清除本次旧入口，明确“本批未生成”。保留单独JSON导出快捷入口，但也经过同一输入边界和不可变快照；它不是与其他批次文件混用的套件。

## PNG语义与限制

设计区PNG和游戏窗口预览图是不同产物。本批仅提供前者，**不导出后者**。即使从游戏窗口预览状态触发导出，也只按权威designSize生成设计区参考图，绝不把GUI Scale或网页Zoom/DPR烘入尺寸。

干净PNG不绘制坐标轴或辅助标记；坐标语义同时在导出界面、manifest/实现规格/Prompt中明确，并写入PNG的MinecraftGuiMaker tEXt元数据（含批次、revision、文档摘要、类型、尺寸、单位及原点）。因此参考图不会被误称为带窗口缩放的截图。元数据不是新的权威模型。

四组件使用中性网页自绘，文字按浏览器字体及translate.fallback显示；不加载游戏资产，不承诺游戏内字体、换行、颜色/禁用态、资源包或语言一致性。初始visible=false的组件不绘制；不可见组件仍完整存在权威JSON与实现规格。背景kind=none对应PNG透明底。

为防止单图分配过大，D限制每轴≤8192且总像素≤16,777,216；超过时明确拒绝PNG及整批导出，**不缩放、裁切或修改设计**。单独JSON仍可导出合法大设计。这是浏览器导出操作限制，不是Minecraft或Schema上限。toBlob失败、context不可用、摘要不可用等也明确失败。

## Prompt的证据分层

- **facts**：经目录/目标校验确认的Minecraft Java 1.21.1、NeoForge21.1.244、Java21；Button/EditBox/StringWidget为审计确认的原版类，fill为GuiGraphics绘制方法，不冒充独立Widget。列构造入口类型与审计定位。只称源码静态确认，不称游戏运行验证。
- **designIntent**：项目声明的设计区尺寸、center放置、数组绘制顺序、节点bounds/初态/文字属性与空事件。位置分区说明为派生描述，不推断锚定、响应式约束或未声明行为。
- **unverified**：网页与游戏的文字度量/视觉保真、真实输入与旁白、游戏内GUI Scale视觉、跨输入法/物理DPR/其他浏览器、服务端行为等继续OPEN。不能把这些写成完成事实。

Markdown不得让用户文字被解释为额外实现指令；标题/表格只使用受限ID或固定文本，文字属性以JSON字面量代码块展示，保留翻译键与预览文字的区别。Prompt明确以project.json为准，派生内容冲突或不明处交由实现者核对；不编造按钮逻辑或网络权限实现。

## 验收门槛

自动化覆盖：合法未提交文字/属性/设计尺寸导出，非法输入阻止、快照深冻结、异步生成期间继续编辑仍保持同批一致、revision/摘要关联、JSON重新导入等价、结构化三分层与来源准确、Markdown特殊字符处理、PNG尺寸/透明底/像素/元数据、无编辑辅助元素、Zoom/Pan/DPR/游戏预览隔离、隐藏初态、编码/容量异常、重复导出及资源清理、无草稿时历史/文档/选择不变。A+B+C完整回归继续通过。

真实游戏、其他浏览器和系统级故障等既有OPEN不自动关闭。冻结合同的变更需另记版本或明确差异，不静默改写语义。
