# M1 导航身份合同

M1-F 更新：0.13.0 的显式项目入口与用户确认的定向导航生命周期见 [M1-F 合同](M1F_RUNTIME_EXPORT_CONTRACT.md)。声明／真实 Screen 的稳定身份和显式绑定继续保留；下文实施状态为历史。

用户已选择保留 F1 声明目标，并显式绑定真实 Screen。该文档冻结实施意图，**不表示功能已实现**。

- 建议以 Schema 0.12.0 引入真实多 Screen 和目标可选绑定；旧版本继续仅支持一个 Screen，禁止携带绑定字段。读取旧项目不得迁移、写回或重写规则。
- 声明目标和真实 Screen 的 ID 分属不同实体，仍与项目、节点及规则 ID 全局不重复。绑定字段指向真实 Screen 的稳定 ID；不按名称匹配。多个声明可绑定同一真实 Screen，单个声明最多绑定一个。未绑定目标保留 F1 声明语义。
- 创建第二个 Screen 与版本升级是同一历史事务；绑定、解绑和重命名可撤销。删除被绑定 Screen 前必须解除绑定。目标声明的旧规则仍引用声明 ID，不能静默改写。
- 当前 Screen 是统一编辑器会话状态，不写入项目 JSON 或设计历史；切换时应处理未提交草稿，清除节点选择与临时预览，避免编辑错误 Screen。撤销或导入导致当前 Screen 消失时应安全回退。
- 同批导出使用项目级权威快照及资源、字体会话；每个真实 Screen 生成唯一文件名的参考图，规格、Prompt 和 manifest 区分未绑定声明、已绑定声明和真实 Screen。未绑定声明不生成画布。

实际 Schema、编辑器、导出与验证尚待实施；现有项目不得视为已支持多 Screen。
