# UI-R1A 工作区与入口迁移

## 工作区偏好

`minecraft-gui-maker.workspace-preferences.v1` 是浏览器 origin 级 localStorage 项，含版本、左右侧栏模式（固定、手动收起、自动隐藏）、各自上次固定宽度和左侧项目树高度比例。读取异常或版本不匹配使用默认布局，写入失败不阻断设计。宽度恢复时按窗口约束；临时浮出、悬停、菜单和弹窗状态不保存。数据不进入设计 JSON、IndexedDB 设计记录、历史和导出。

自动隐藏或手动收起的侧栏可从画布边缘临时浮出并覆盖画布，固定按钮将它变为常驻；鼠标离开延迟收起，焦点仍在侧栏或正在拖动时保留。拖动宽度低于阈值时收起并保留拖动前宽度。左侧上方为可滚动项目结构，下方为可滚动组件库，中间分隔可拖动。视图缩放与平移继续由 Canvas 自己维护，布局尺寸不是文档坐标。

## 入口迁移对照

| 原功能及入口 | UI-R1A 入口 |
| --- | --- |
| 顶栏导入 JSON、JSON 备份、生成规格、ZIP | 顶栏原按钮保留；文件菜单提供相同真实操作；PNG、放大图、规格、Prompt、manifest、Panel 图仍在生成结果中逐项下载。 |
| Inspector 未选中时的项目名称、资源检查、本地保存和副本 | 全局工具栏常驻，选中节点后仍可使用；本地副本菜单仍支持保存、切换及恢复。 |
| Inspector 未选中时的撤销/重做、选择/平移、网格、Zoom/Pan、GUI Scale | 全局工具栏常驻；编辑、视图和工具菜单提供相应真实操作；快捷键规则保持原有实现。 |
| 组件库及节点图层 | 左侧下方组件库与上方项目结构；原点击、拖放及图层选择保留。 |
| Canvas 节点选择、移动、双击编辑、交互预览与标签编辑视图 | 中央 Canvas 和右侧 Inspector；标签编辑视图仍为会话状态。 |
| Inspector 组件属性、画布尺寸、Panel 独立几何 | 右侧 Inspector；画布尺寸常驻，Panel 设置在未选中节点时可用。 |
| 顶栏行为面板、F0/F1/F2 和 CreativeTab 测试 | 顶栏原行为按钮及模式菜单；行为浮层复用既有实现。 |
| 预览字体文件与系统回退 | 全局工具栏，仍为资源会话状态。 |
| 资源 ZIP/目录、客户端 JAR、Sprite 查询 | 全局工具栏的资源检查；资源解析器及生命周期未重写。 |
| 导出状态、保存状态、设计大小、缩放与资源 | 底部状态栏与原导出/本地副本面板；设计数据未增加偏好字段。 |
| JSON 只读预览、编辑状态和历史计数 | 画布底部原位置。 |
| 帮助 | 帮助菜单显示已有快捷键说明，不提供未实现功能。 |

此前工具栏放在 Inspector 未选中区域，选择节点会隐藏屏幕级工具；本批将这些工具提升为全局入口。行为浮层位置仍在中央工作区，这是 UI-R1A 范围内的保留方式，不代表完成任意停靠框架。
