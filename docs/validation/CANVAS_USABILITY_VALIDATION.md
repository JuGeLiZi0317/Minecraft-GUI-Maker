# 画布可用性验证

2026-10-28，Windows 上使用 Chrome 156.0.8078.48，通过 Playwright Chrome 通道运行，视口 1440×1000，模拟 DPR 1 和 2，各 51 项，共 102 项通过、0 失败、0 跳过。原始结果见 [canvas-usability-results.json](canvas-usability-results.json)。`npm.cmd run build`（含 typecheck）通过，Vitest 66 项通过。

覆盖普通滚轮围绕光标缩放、右键平移、缩放到 1600%、网格显示与 1 和 200 逻辑像素边界、无效间距、三个浮层点击外部关闭、未提交草稿及导出批次保留。网格是视图辅助，不进入 JSON、历史或设计区 PNG。另覆盖旧自绘及 32× 项目读取和导出，旧选项不能用于新设计。

首次专项中，Playwright 对禁用的 option 的 `toBeDisabled` 断言误判；改为断言 DOM 的 disabled 属性后通过。首次完整回归中，旧本地保存测试在点击外部使面板收起后仍直接点击面板按钮而超时；测试调整为重新打开面板后，本地保存专项 28 项和完整回归 102 项均通过。

用户报告其实际游戏测试中 GUI 已与原版一致；该反馈仅覆盖用户所测情况，不代表所有分辨率、GUI Scale、资源包或组件均已验证。模拟 DPR 不等于物理屏幕测试，真实输入法、多浏览器、不同设备和更广泛的游戏内视觉一致性仍为 OPEN。
