# 字体验证计划（PENDING）

固定并记录客户端和 NeoForge 版本、用户资源层及指纹、语言、窗口尺寸、GUI Scale、游戏字体选项、浏览器版本、DPR、截图与资源诊断。合成资源用于自动化；游戏资产仅由用户本地提供，不放入测试产物或构建。

| 样例 | 对照重点 |
|---|---|
| Button：短文本、长文本、数字/标点/大小写 | 居中、滚动、裁切、阴影与 disabled 颜色 |
| EditBox：value、空 value + hint、焦点、溢出、小尺寸 | hint 条件、宽度、显示位置、光标及裁切 |
| StringWidget：左右中对齐、长文本 | advance、取整、基线、省略和裁切 |
| 中文、未知字符、混合 Unicode、双向文字 | 实际 provider 来源、缺失回退、视觉顺序 |
| 加粗、斜体、阴影、不同 GUI Scale | 字形偏移、颜色及缩放差异 |

先比较源码规则、逻辑坐标与 glyph advance，再比较固定条件下截图像素；字体光栅与平台差异须单列容差和原因。浏览器测试不能替代实机，用户资源及测试范围外的 provider 不得标记为一致。当前仅完成资源可用性独立实验，以上游戏对照、完整实现与视觉一致性均为 PENDING。
